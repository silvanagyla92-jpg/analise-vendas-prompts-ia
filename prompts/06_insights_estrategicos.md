# Prompt 06 — Insights Estratégicos

## 1. Objetivo

Consolidar os resultados das análises anteriores e transformar evidências em insights úteis para tomada de decisão, mantendo separação entre fatos, interpretações e recomendações.

## 2. Prompt

### 2.1 Instrução para a IA

```text
Atue como um analista de negócios responsável por transformar resultados de uma análise de vendas em insights estratégicos.

Utilize somente os resultados e evidências fornecidos nas análises anteriores. Não invente dados, métricas ou causas que não estejam documentadas.

Para cada insight, siga esta estrutura:

1. Evidência — o que os dados demonstram objetivamente.
2. Interpretação — o que essa evidência pode significar para o negócio.
3. Impacto potencial — por que o achado pode ser relevante.
4. Recomendação — ação que poderia ser considerada.
5. Dados adicionais — informações necessárias para confirmar ou aprofundar a hipótese.
6. Confiança — alta, média ou baixa, justificando a classificação.

Priorize os insights segundo:
- relevância para o negócio;
- magnitude do efeito observado;
- consistência entre diferentes análises;
- possibilidade de ação;
- qualidade das evidências.

Organize os principais achados em uma matriz:

| Prioridade | Insight | Evidência | Impacto potencial | Recomendação | Confiança |

Depois, responda:
- Quais são os 5 principais insights?
- Quais produtos merecem atenção?
- Quais períodos apresentam maior risco ou oportunidade?
- Quais clientes ou padrões de clientes merecem investigação?
- Quais regiões apresentam maior potencial ou necessidade de atenção?
- Quais informações ainda estão faltando para uma decisão mais segura?

Diferencie explicitamente:
- Fato observado;
- Inferência;
- Hipótese;
- Recomendação.

Não transforme uma correlação em causalidade.
Não apresente uma recomendação como se fosse uma conclusão comprovada.
Não invente valores para preencher lacunas.

Finalize com um resumo executivo de até 10 linhas, adequado para apresentação a um gestor.
```

## 3. Critérios de Validação

### 3.1 Verificações

- Cada insight deve possuir uma evidência rastreável.
- Recomendações devem estar relacionadas aos achados apresentados.
- Hipóteses devem ser identificadas como hipóteses.
- Nenhum número pode ser introduzido sem origem nos dados ou análises.
- Deve existir coerência entre os resultados específicos e a síntese final.

## 4. Resultado Esperado

Uma síntese executiva dos principais achados da análise, acompanhada de recomendações e limitações, permitindo demonstrar como prompts podem apoiar a interpretação de dados e a tomada de decisão.
